# 25 — FAQ Técnico
**Onde alterar regra de frete?** Primeiro determine se é dado da tabela ou motor. Nunca implemente fórmula em `app.js`.

**Onde ficam dados de produção?** `/data` no Docker; localmente em `web_local/data`/workspaces.

**PostgreSQL substitui Base SSW?** Não nesta versão.

**Assinatura é ICP-Brasil?** Não; é visual no PDF.

**Por que há legacy/patches?** Compatibilidade durante modularização; não remover sem regressão.

**Projeto usa OpenAI?** Não no código auditado.

**Repo pode ser público?** Tecnicamente sim, mas contém tabelas comerciais; validar confidencialidade/licença/autorização.
