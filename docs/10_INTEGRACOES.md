# 10 — Integrações Externas
- **SSW/.sswweb:** fonte oficial operacional da base de fretes.
- **PostgreSQL SSW:** sombra/read-only, direto ou ponte PowerShell; sem promoção automática.
- **Cloudflare Quick Tunnel:** HTTPS temporário `trycloudflare.com` para Windows local.
- **Caddy/Let's Encrypt:** domínio, TLS e reverse proxy em produção.
- **S3 compatível:** backup externo opcional.
- **Webhook:** alertas do monitor; provedor não fixado.
- **GitHub:** fonte de código/deploy; dados operacionais devem ficar fora.

**OpenAI:** NÃO DETECTADA no código auditado.
