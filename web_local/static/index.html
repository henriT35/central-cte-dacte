Homologação global

Base SSW Web

A Base é um conjunto de planilhas .sswweb. A importação substitui o conjunto importado anterior somente depois da validação completa.

PostgreSQL SSW — somente leitura

Integração PostgreSQL mantida em modo sombra na R12.13. O snapshot do banco pode ser comparado com a Base SSW, mas não substitui automaticamente os arquivos .sswweb nem altera o motor RC26.6.
