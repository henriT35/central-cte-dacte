# Base SSW

Os arquivos operacionais `.sswweb` **não ficam no Git**.

Depois do primeiro deploy, entre com o perfil **Desenvolvedor** e importe o conjunto oficial da Base SSW pela interface do sistema.

Motivos:
- podem conter dados operacionais/reais;
- mudam com frequência;
- são grandes;
- não pertencem ao código-fonte.
